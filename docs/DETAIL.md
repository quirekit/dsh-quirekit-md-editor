Open a Markdown file from the Files tab and edit the rendered document directly. Changes save back to the file, and text you did not edit stays byte-for-byte identical.

If an agent changes the file while you have unsaved text, the editor asks which version to keep. Use the document toolbar menu to switch back to the built-in Markdown preview.

Built on [QuireKit MD Editor](https://msfe.quirekit.com/en/md-editor/).
